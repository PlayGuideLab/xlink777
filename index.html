可发外链的位置

第一回复（最推荐）

主帖发完整有价值的内容，发完立刻自己回复第一条放链接。这是目前最推荐的方式，曝光最好，想点链接的人也能轻松找到。

Bio / 置顶帖（最安全）

长期链接放在个人资料或置顶帖，主帖引导用户去看。不受单帖算法影响，最稳定。

主帖直接放

2026年官方已确认无链接惩罚。适合帖子核心就是引导点击的场景，仍建议自己账号实测。

实用技巧

  • 主帖必须独立有价值，不要让用户必须点链接才能获得信息。
  • 加图片或视频比纯文字+链接效果更好。
  • Premium 账号发链接表现明显好于普通账号。
  • 建议做 A/B 测试，观察自己账号的真实数据。

方法论

  • 保留平台停留时间：主帖不放链接可减少退出意图信号。
  • 强钩子 + 引导回复：主帖用强钩子和问题引导互动，再在回复中提供链接。
  • Link-in-bio 聚合：多个链接用聚合页面管理，Bio 只放一个入口。

最新案例与讨论

日更 GitHub 仓库做外链

@ai_chuhai 提出的方法：做一个日更的 GitHub 仓库，在 about 和内容里带上网站锚文本，让 Google 认定你是专业活站。

@FanShifu 补充：建仓库定期更新项目版本，目的就是让 Google 认定你是专业性强的活站。这事可以让 bot 自动做。

其他方法（预印本论文、亚马逊出书等）成本较高，更适合品牌站。新手优先考虑 ROI。

评论提醒：仓库更新好办，但别最后全是 bot 在改 README。
